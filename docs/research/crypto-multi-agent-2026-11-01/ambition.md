# Research brief

Goal beyond the goal: determine whether agent communication adds measurable decision value after costs, rather than assembling an impressive-looking trading conversation.

Altitude: (1) identify relevant systems; (2) choose a communication protocol from evidence; (3) prospectively test incremental value against simpler alternatives. This review reaches rung 2 and specifies rung 3 without claiming to have run it.

Depth: use original papers, official release status and existing local contracts. Separate voting from discussion with paired first answers and a compute control. The hard target is a defensible recommendation whose key claims survive independent source review and whose proposed experiment can falsify it.

Range: combine financial experimental design with distributed-system failure analysis and adversarial message testing. Parallel finance/protocol researchers were attempted, but account limits prevented their work. A subsequent independent critic ran and identified specification gaps; a fresh critic passed the corrected report.

Available: public papers/repositories, existing R1 data and local code. Missing: point-in-time intraday/news data, authorized model experiment budget and prospective outcomes. No paid execution or trading is implied.

Rewritten brief:

```text
Research agents both producing and choosing crypto trading signals. Read the original studies and check what official repositories actually release. Compare a single analyst, independent voting, bounded debate and a compute-matched control. Explain how communication changes evidence, how shared errors and malicious sources propagate, and how deterministic rules preserve authority. Recommend a protocol for our local-Claude-only research environment and specify a falsifiable prospective comparison. Pass only after an independent critic checks the sources and can follow the experimental protocol; do not substitute reported backtests for verified profits.
```
