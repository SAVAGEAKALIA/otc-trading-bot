The archived Telegram runtime is restored from `archive/otc-binary` (569fc42). That commit already belongs to the current branch's ancestry; merging it alone cannot undo the later source deletions. The restoration keeps current crypto modules.

The practice deployment runs the archived MHI strategy as `archived_mhi3_exploratory_v1`. It uses one strategy vote, one independent family, fixed 2-minute duration, USD1 stake and a fixed lexical scan order among currently eligible OTC assets; the archived score ranking and currency deduplication select the admitted candidate. This score is heuristic, with no calibrated win probability or verified edge. The stricter `legacy_mhi3_causal` research slot is separate: the legacy scanner cannot supply its required typed contract, receipt-clock and finalized-revision evidence. New strategies have software acceptance checks; economic acceptance remains unproven. Archived outcome blacklisting remains at12 decided trades and a0.38 win-rate cutoff, so future eligibility can depend on prior verified outcomes.

Only current explicit enabled/unsuspended turbo offers with at least 80% payout and an offered expiry 90–150 seconds away admit orders. The order stores its offer, fixed stake, actual submitted expiry, strategy context and exact PRACTICE balance ID before sending once. Ambiguous submission stays UNKNOWN and blocks every trading route after restart. Accepted orders recover from the durable ledger. Settlement requires matching broker closed-option cash evidence; balance movements and timeouts cannot produce a win or loss. One position, 100 requests per UTC day and USD20 verified daily loss are fixed research budgets. The bot never resets balances or switches to REAL.

Telegram Saved Messages: `/status`, `/stats`, `/breakdown`, `/session`, `/trades`, `/balance`, `/pause`, `/resume`, `/scanner on|off`, `/telegram on|off`. `/stop` pauses trading. Unneeded mutable sizing, account-switch, martingale, model, reset and threshold commands are unavailable. A pause stops new order admission while settlement monitoring continues.
